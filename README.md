# STM32 温度与状态监测控制项目

基于 STM32F103C8 的嵌入式项目，使用热敏电阻测温，并结合压力、液位传感器进行状态检测。工程使用 Keil MDK-ARM 和 STM32F10x 标准外设库。

## 功能

- 采集热敏电阻温度，并通过定时器 PWM 控制加热输出。
- 使用 HX711 读取压力信号并进行阈值检测。
- 使用反射式红外传感器检测液位状态。
- 通过 OLED 和按键显示、调整系统状态及目标温度。
- 通过 USART1 定期输出温度、液位和压力状态，也可接收串口命令。

串口命令（USART1，9600 baud）：

| 命令 | 功能 |
| --- | --- |
| `s` | 输出当前温度、液位和压力状态 |
| `h` | 输出命令帮助 |

## 硬件引脚

| 功能 | 引脚 |
| --- | --- |
| 热敏电阻模拟输入 | PA0 / ADC1_IN0 |
| 加热控制输出 | PA1 / TIM3_CH2 |
| OLED 按键上 / 下 | PA2 / PA3 |
| USART1 TX / RX | PA9 / PA10 |
| HX711 SCK / DT | PB6 / PB7 |
| 液位传感器 DQ / AQ | PB12 / PB13（AQ 为可选输入） |
| 使能控制 | PB4 |

请在连接硬件前核对实际模块的供电、电平和引脚定义。

## 编译与下载

1. 使用 Keil MDK-ARM 打开 `Project.uvprojx`。
2. 选择 `Target 1`，编译工程。
3. 连接 STM32F103C8 开发板并下载程序。
4. 使用串口终端连接 USART1，设置为 9600 baud、8 数据位、无校验、1 停止位。

## 传感器校准

热敏电阻参考电阻、B 值和 HX711 压力检测阈值在 `Hardware/TempHeat.h` 与 `Hardware/Pressure.h` 中定义。实际使用前应根据传感器和电路参数校准这些值。

## 目录结构

- `Hardware/`：温度、压力、液位、OLED、按键、控制和串口模块。
- `Library/`：STM32F10x 标准外设库。
- `Start/`：Cortex-M3 与 STM32F10x 启动文件、系统文件。
- `User/`：应用入口和中断处理。
- `Project.uvprojx`：Keil 工程文件。
