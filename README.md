# STM32 温控与状态监测

基于 STM32F103C8 和 STM32F10x 标准外设库（SPL）的 Keil MDK 工程。当前固件为裸机周期调度，尚未集成 RTOS。

## 功能与当前实现

- 使用 NTC 热敏电阻和 ADC1_IN0 测温；采样包含中值滤波、滑动平均、B 值换算和输入范围检查。ADC 校准及单次转换有有限等待。
- 使用 HX711 读取压力；数据未就绪等待约 250 ms 后报告读取失败。超时时间依赖 TIM2 配置。
- 使用反射式红外传感器的数字输出检测液位。
- 状态机包含关闭、待机、加热、保温和错误状态；温度、压力、液位故障可区分，软件故障时关闭加热输出。液位故障还会撤销系统使能。
- 控制周期约 100 ms，按键扫描约 10 ms，串口状态每秒上报一次；这些周期由 TIM2 时基驱动。
- OLED 显示状态；上下按键以 5°C 为步进调整 30–100°C 的目标温度。
- USART1 使用 9600 baud、8N1。`s` 输出状态和故障原因，`h` 输出帮助。RX 环形队列 128 字节（127 字节可用），TX 队列 256 字节（255 字节可用）；队列满时丢弃新字节并累计溢出计数。

### 加热输出说明

当前 PA1 是普通 GPIO 开关输出：传入非零功率时打开，传入 0 时关闭。控制模块计算的 0–100 功率值**没有对应 PWM 或比例调功实现**；头文件中的 TIM3_CH2 定义不代表 PWM 已配置。接入前须确认实际器件是机械继电器还是 SSR，并据此设计适合的输出策略。

## 硬件引脚

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| NTC 模拟输入 | PA0 / ADC1_IN0 | 分压参数需按实际电路校准 |
| 加热开关输出 | PA1 | GPIO 开/关，非 PWM |
| 温度上调 / 下调 | PA2 / PA3 | 上拉输入 |
| USART1 TX / RX | PA9 / PA10 | 9600 baud、8N1 |
| HX711 SCK / DT | PB6 / PB7 | 压力阈值需实物标定 |
| 液位传感器 DQ | PB12 | 数字输入 |
| 液位传感器 AQ | PB13 | 当前固件未使用 |
| 系统使能 | PB4 | 初始化时关闭 JTAG、保留 SWD；使用 SWD 调试/下载 |

引脚表来自固件宏定义，不代替原理图核对。连接前确认供电、电平、信号极性和模块实际引脚。

## 编译与下载

1. 使用 Keil MDK 5 打开 `Project.uvprojx`，目标为 `Target 1`、STM32F103C8。
2. 工程配置使用 Arm Compiler 6.24 和 C99；执行 **Rebuild All** 后检查 Build Output。命令行示例：

	```powershell
	& 'D:\keil5\UV4\UV4.exe' -r 'Project.uvprojx' -j0
	```

3. 使用 SWD 下载和调试。最近一次本机全量构建结果为 0 errors、95 warnings；警告主要来自旧 OLED 字库初始化格式。构建通过不等于硬件功能已验证。
4. 串口终端设置为 9600 baud、8 数据位、无校验、1 停止位。

## 校准与安全

- NTC 参考电阻、B 值和 HX711 阈值定义在 `Hardware/TempHeat.h` 与 `Hardware/Pressure.h`；需按传感器和分压电路实测校准。
- 软件检测与 GPIO 关断不能替代独立热熔断器/温控器，也不能处理继电器触点粘连。首次接入加热负载前，使用无功率或安全替代负载验证默认关闭、传感器故障关断和系统使能极性。
- 当前没有目标板测试结果；温度精度、HX711 时序、液位极性、SWD 下载和加热安全尚未实测。

## 目录结构

- `Hardware/`：传感器、温控、显示、按键和串口模块。
- `Library/`：STM32F10x 标准外设库。
- `Start/`：Cortex-M3/CMSIS、启动和系统文件。
- `User/`：应用入口、中断和配置。
- `Project.uvprojx`：Keil 工程及 Arm Compiler 6 配置。
